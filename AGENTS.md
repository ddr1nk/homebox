# Контекст проекта для ИИ-агентов

HomeBox — self-hosted система домашнего инвентаря. Начинай с [карты проекта](docs/ai/PROJECT.md), затем читай [архитектуру и инварианты](docs/ai/ARCHITECTURE.md) и [разработку и проверки](docs/ai/DEVELOPMENT.md).

## Главное перед изменениями

- Backend: Go, Chi, Ent, Goose; SQLite и PostgreSQL. Frontend: Nuxt/Vue SPA, TypeScript, Pinia, Tailwind, shadcn-vue. UI в production встроен в Go-бинарник.
- Актуальная модель — `Entity` + `EntityType.is_location`. Вещи и места хранения используют общую таблицу и дерево `parent/children`. Названия `items`, `locations` в UI и некоторых файлах исторические.
- `Group` в backend = коллекция в UI = граница изоляции данных. Пользователь состоит в нескольких коллекциях; роль владельца хранится в `UserGroup`, а не является глобальным правом.
- Для запросов от пользователя сохраняй tenant-проверки и group-scoped методы репозиториев. Проверяй также принадлежность связанных UUID: parent, tags, templates, entity types, attachments.
- Схемы меняются в `backend/internal/data/ent/schema/`; учитывай миграции **обоих** драйверов. Ent-код, Swagger и TypeScript-контракты обновляются генераторами, а не ручной правкой результата.
- Календарные даты не равны timestamp: используй `backend/internal/data/types/date.go` и `frontend/lib/datelib/dateOnly.ts`.
- `task go:run` включает demo и отключает хеширование паролей специальным dev-флагом. Не направляй его на рабочие данные. Обычный сервер требует `HBOX_AUTH_API_KEY_PEPPER` длиной минимум 32 байта.
- Интеграционные тесты используют живой API и изменяют данные. В Vitest teardown строка `TEST_SHUTDOWN_API_SERVER=false` всё равно включает `pkill`; для сохранения сервера переменная должна отсутствовать.
- Сверяй версии с манифестами: старые prerequisites в `CONTRIBUTING.md` устарели. Команды Taskfile и npm-скрипты местами рассчитаны на POSIX shell.

## Как поддерживать контекст

При изменении бизнес-логики, API, схемы, конфигурации или процесса сборки обновляй соответствующий файл `docs/ai/`. Факты в коде и текущих манифестах приоритетнее этой сводки. Не представляй документированные команды как успешно выполненные без их запуска. Для файлов внутри `.github/` дополнительно прочитай `.github/AGENTS.md`.
